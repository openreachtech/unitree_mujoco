# 2S1 heightfield for MuJoCo (福岡造船 呉工場 設計DXF実測)

## 中身
- 2s1_top.png / .npy    : タンクトップ上面。基準=板面(z=1.59)。突出部材 最大0.190m
- 2s1_bottom.png / .npy : 二重底内部。基準=内底板(z=0.02)。ロンジ0.23m / ガーダー等は
                          0.6mクリップの壁。フロア/ガーダーの区画格子が実寸で出る
- scene_2s1_top.xml / scene_2s1_bottom.xml : そのまま開ける確認用シーン
- usd2hfield.py         : 生成スクリプト (blocks/2S1.usd から。範囲/解像度変更可)

## 仕様
- 500x800px, 1px=20mm, 範囲 x±5m y±8m (ブロック中央部)
- 高さ 0..0.45m(top) / 0..0.60m(bottom), 8bit → 1step 1.8/2.4mm
- MJCF: <hfield size="5 8 0.45 0.10"/> (rx ry 標高 ベース厚)

## 表示
python -m mujoco.viewer --mjcf scene_2s1_bottom.xml
(ヘッドレスなら MUJOCO_GL=osmesa でオフスクリーン可)

## 検証済み
- 構造プロファイル一致 (ガーダー±1.6/±3.1m、防撓材0.23m、ビルジ、区画格子)
- 球ドロップで接地確認 (ベイ床/上面とも)

## 注意 (重要)
- ロンジ天端の「通路」はフロア近傍のフランジの寄せ集めで、ベイ中間では
  連続していない (実データの事実)。Isaacのキネマティックデモは支持面を
  問わないため歩けて見えるが、物理ポリシーは落ちる。歩行課題は
  1) top: 平板+突出0.19m乗り越え、2) bottom: ベイ内移動+ロンジ0.23m跨ぎ、が現実的
- 人通孔くぐり(伏臥)は velocity ポリシーの守備範囲外。別課題
