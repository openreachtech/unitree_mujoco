# 2s1_gate_scene (実人通孔が「開いた」MuJoCoシーン) - 先のzipへの追加分

## 中身
- scene_2s1_gate.xml : 人通孔を挟む2区画 (2.5x3.2m)。開口 760x560mm/敷居480mm が
                       物理的に開いている。python -m mujoco.viewer --mjcf scene_2s1_gate.xml
- 2s1_gate.png       : 周辺構造の hfield (1px=10mm)
- make_gate_scene.py : 生成スクリプト (孔座標を変えれば他の孔にも)

## 作り
heightfield は各(x,y)に高さ1つの2.5D表現で、縦板の穴を持てない。そこで
ハイブリッド構成にした:
  周囲の防撓材/ガーダー = hfield (実形状のまま) + 対象フロアだけ箱4枚で
  再構成 → 実寸の開口が開く
座標系: 孔中心=原点 / 内底板=z0。開口は矩形近似 (実形状は隅が丸い)。

## 検証済み
- レイキャスト: 孔中心は素通り / 孔の横・敷居下は壁に命中
- 球をベイに落とす → 接地 / 球を孔へ射出 → 反対側のベイへ通過
